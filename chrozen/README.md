# Chrozen Electron port

This directory contains the experimental Electron entry point for the Chrozen fork of Zen Browser. It uses the original Zen design tokens under src/zen. The original Gecko build remains in the repository.

To run the Electron port from this directory, use npm install and npm start.

The current port supports creating, selecting and closing vertical tabs, opening web pages and navigating their history. Spaces, Glance, Split View, Compact Mode and mod support are pending.
